# 원칙 카드 — Charverse v2

> 각 카드는 원칙·근거·적용·시연·판단 다섯 칸을 코드와 설계 논의에 연결한다.
> 코드 근거는 `lib/`의 화면과 위젯을 가리킨다. 근거 칸은 유사앱 스크린샷과 스토어 리뷰 이미지(작성자 이름 제거), 시연 칸은 실행 중인 Charverse 웹 화면 캡처를 기준으로 하며 발표자료 부록 1-1 ~ 1-10과 같은 내용이다.

## 유사앱 캡처 참고

첨부 캡처에서 관찰한 화면 패턴은 아래 원칙 카드의 근거로 사용한다. 캡처는 UI 사례이며, 리뷰·사용성 테스트 데이터나 기능 효과를 입증하는 실험 결과는 아니다.

| 캡처 관찰 | 관련 원칙 | Charverse에서 참고한 점 |
|---|---|---|
| 손글씨 분석에서 모범 글씨/내 글씨, 획수, 피드백과 `고쳐 쓰기`를 함께 표시 | P01, P05, P09 | 기준·상태·다음 행동을 한 흐름에 두고, 진단은 사전 작성 예시로 제공한다. |
| 한자 `間`을 뜻, 구성 요소, 삽화, 문맥 문장과 함께 설명 | P02, P06 | 글자의 실제 명칭과 뜻·문맥으로 재인성을 돕는다. |
| 학습 홈에서 신규·복습·완료 수와 학습 전략을 제시 | P01, P03, P07 | Charverse의 학습 상태와 글자 수 표시를 참고한다. |
| 목표 선택, 전략 설명, 단계별 필기 안내와 `팁 건너뛰기`를 제공 | P03, P07, P10 | 선택과 도움말의 명확성을 참고하고 현재 A/B/D 흐름에 적용한다. |

첨부된 스토어 화면에는 App Store 평점 4.9와 1.1만 개 평가, Google Play 평점 4.9와 리뷰 2.85천 개가 표시되어 있다. 리뷰 PDF의 20건 표본은 기능 요청 11·버그 4·평가 3·사용 경험 2건이며, 표본 평균은 4.30/5다.
